# V5.8b — politique des robots d'IA : on autorise les robots de RECHERCHE, qui servent à
# citer le site dans les réponses (ChatGPT, Perplexity, Claude). Un pare-feu ou un
# hébergeur qui bloque par défaut les retirerait sinon de ces réponses.
#
#   OAI-SearchBot  recherche de ChatGPT        → autorisé
#   PerplexityBot  recherche de Perplexity     → autorisé
#   Claude-SearchBot recherche de Claude       → autorisé
#
# Volontairement PAS nommés, donc soumis au groupe « * » :
#   GPTBot, ClaudeBot, Google-Extended : jetons d'ENTRAÎNEMENT des modèles, pas de
#   recherche. Tant qu'ils ne sont pas nommés ils restent autorisés par « * », comme avant
#   ce lot. Les bloquer ou non est une décision de la cliente : pour bloquer l'un d'eux,
#   ajouter un groupe « User-agent: <nom> » suivi de « Disallow: / ».
#
# Un groupe nommé remplace le groupe « * » pour ce robot : le Disallow est donc répété.
